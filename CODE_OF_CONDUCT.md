# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), as its code of conduct. It applies to everyone in every project space: issues, pull requests, reviews, discussions, and any other channel where someone represents the project.

In short: be respectful and constructive, assume good faith, and do not harass, demean, or publish anyone's private information. Never post a real credential or someone else's personal data, even as an example.

## Reporting

Report unacceptable behavior to the maintainer, [@milocosmopolitan](https://github.com/milocosmopolitan), through the contact details on their GitHub profile. Do not report it in a public issue. Reports are handled privately, and the reporter's identity is not disclosed without consent.

## Enforcement

The maintainer reviews every report and decides on a response following the Contributor Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines): correction, warning, temporary ban, or permanent ban, depending on severity.
